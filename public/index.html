    怎么拿到密钥？（以 DeepSeek 为例）
    1. 打开 platform.deepseek.com 注册并登录
    2. 左侧选「API keys」→「创建 API key」→ 复制那串 sk- 开头的字符

    4. 回到这里粘贴，点「保存并启用」

    其他服务商同理，选对应平台注册后创建密钥即可。密钥仅保存在你浏览器的本地存储中， 不会上传到本站服务器（本站也根本没有服务器）。换电脑或清理浏览器数据后需要重新填写。
